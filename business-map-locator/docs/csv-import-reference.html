Business Map Locator

CSV Import Reference

Prepare UTF-8 CSV files for reliable location imports. Comma, semicolon and tab delimiters are supported and detected automatically.

Required structure

Required columns

title or name, plus lat and lng.

Recommended identity

Always provide a stable and unique external_id for safe updates.

Supported columns

ColumnPurposeAccepted format
external_idStable business-system identifier.Unique text, for example STORE-001.
title / nameLocation name.Required non-empty text.
addressStreet address.Plain text.
cityCity taxonomy terms.One or more values separated with |.
categoryCategory taxonomy terms.One or more values separated with |.
region, country, postcodeAddress details.Plain text.
lat, lngCoordinates.Decimal point only: 53.900601, -27.558972.
phone, email, websiteContact information.Phone text, valid email, full URL.
hoursOpening hours.Plain text, quoted when it contains delimiters or line breaks.
statusWordPress publication status.publish or draft. Values 0, false, no, inactive and disabled become draft.
visibleFrontend visibility flag.True: 1, true, yes, on, visible. Other values become 0.

File rules

  • Use UTF-8 or UTF-8 with BOM.
  • Line endings may be LF or CRLF.
  • Quoted multiline fields are supported.
  • Empty rows are skipped.
  • Header names must be unique.
  • Unknown columns are rejected by default.

Duplicate safety

A repeated external ID, an ambiguous fingerprint, or a conflict between external ID and fingerprint is reported as an error. The importer will not update a random location.

duplicate_external_id_in_fileThe same external ID appears more than once in the CSV.
duplicate_external_id_in_databaseThe database contains multiple locations with the same external ID.
ambiguous_fingerprintTitle, address and coordinates match multiple locations.
external_id_fingerprint_conflictExternal ID and fingerprint point to different locations.
