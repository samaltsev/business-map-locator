OSM
Активен

OpenStreetMap

Бесплатная карта на базе Leaflet. Подходит для большинства каталогов филиалов и сервисных точек.

  • Не нужен API-ключ
  • Гибкие тайлы и стили
  • Обязательная атрибуция OSM
G
Требует ключ

Google Maps

Привычная карта Google с геокодированием, Places API и высоким качеством адресного поиска.

  • Нужен Google Maps API Key
  • Требуется биллинг Google Cloud
  • Можно ограничить ключ по домену
