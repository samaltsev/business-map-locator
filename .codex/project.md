# NBH Business Locator — проектный контекст для Codex

## Продукт
WordPress business locator для магазинов, филиалов, офисов, дилеров, сервисных центров, клиник, аптек и других физических точек.

## Целевой Free 1.0
- OSM/Leaflet без обязательного Google API key.
- Directory + Map.
- Полноценная карточка и detail.
- Categories и hierarchical Areas.
- CSV dry run/import/update/export.
- Server-side pagination, bounds и radius.
- Shortcode Builder и Gutenberg.
- Четыре layouts и два presets.
- EN/DE/UK/RU.
- Production quality.

## Целевой Pro 1.0
- Services.
- Structured schedules.
- Smart Availability.
- Smart Ranking.
- Saved Locators.
- Per-Locator settings.
- Premium и custom presets.
- Graceful downgrade.

## Главный Definition of Done
Admin input → validation → storage → index → REST → frontend → tests → documentation.
